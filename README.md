# Hakyuha dolls

Tám em doll pixel nhỏ (32px, bằng nút "+") chạy tự do ở dải phía trên ô nhập của app Claude.
Mỗi em một tính cách, có các cặp đôi thả tim, và rê chuột / nhấn giữ vào từng em để tương tác.

> Hình các em là pixel art do người hâm mộ vẽ lại theo các nhân vật doll của nhóm Hearts2Hearts.
> Đây là sản phẩm fan-made, phi thương mại, không liên kết với nhóm hay công ty quản lý.
>
> Eight tiny pixel dolls that roam above the prompt box in the Claude desktop app. Fan-made, non-commercial,
> unaffiliated with the group or its agency.

## Cài đặt / Install

**Bản máy tính (app Claude):** bấm dấu **+** cạnh ô nhập, chọn **Plugins**, chọn **Add marketplace**,
dán `<owner>/<repo>` của kho này, rồi chọn **Add plugin** cho `hakyuha-dolls`.

**Terminal:**

```
/plugin install hakyuha-dolls --marketplace <owner>/<repo>
```

Hoặc trong shell:

```
claude plugin install hakyuha-dolls --marketplace <owner>/<repo>
```

Cài xong, mở một phiên chat mới (hoặc khởi động lại app) là thấy các em.

## Cách chơi

- **Rê chuột** vào một em: em đó làm động tác riêng theo tính cách và hiện biểu tượng.
- **Nhấn giữ rồi kéo**: cầm em đó đi, thả ra thì em đứng yên một lát rồi đi loanh quanh tiếp từ chỗ đó.
- Các cặp đôi (Jjoojebi–Jjuuilien, Toramui–Nohsungie, Jeong–Stellnyang, Bingping–Alssong) hay gặp nhau và thả tim;
  Nohsungie hay ghẹo Jeong; Jjuuilien gặp Nohsungie thì ngại.
